# 公式、来源和资格边界

## 静态公式

输入X包含实现语义、MNK、dtype、完整tiling、核数、布局、缓冲与静态搬运策略。首先按实现源码分配实际MN/K任务，再构造有限缓冲和共享资源约束下的事件图：

```text
d_v(X) = sum_j(theta_j * q_vj(X))
F_v = max(predecessor_finish) + d_v(X)
P(X) = F_sink

S_shared = max(alpha_same * R,
               alpha_issue * Qmax + beta_sum * Wsum + beta_unique * Wunique)

B(X) = T_prior(X) * P_new(X) / P_prior(X)
T_pred(X) = B(X) * exp(clipped fixed static residual)
```

q由静态字节、描述符、16粒度块、MMAD调用及控制任务得到；theta、alpha、beta和外层修正权重都是已经固定的离线参数。T_prior/P_prior也是固定公式输出，不是输入的目标实测值。模型没有按shape索引的耗时表。

事件依赖包含Scalar发射、MTE2 GM→L1、MTE1 L1→L0、Cube、Fixpipe、L1/L0槽释放、累加和输出；完整路径还计入实现已有的转换、初始化、归约/cast。串行费用相加，重叠、引擎可用与共享服务限制取max，因此不是把所有PMU活动耗时相加。

Wsum是静态实际请求的填充源字节总量；Wunique是去重源区域工作；R是静态潜在同源读者cohort；Qmax是最长核请求数。确定性Split-K的不同K分区不能重复按同址peer费用逐事件累加。固定共享参数约为：

```text
alpha_same  = 0.04314060665 us/descriptor
alpha_issue = 0.02123145379 us/descriptor
beta_sum    = 0.11365246583 us/MB
beta_unique = 0.05697601224 us/MB
```

这些是当前实现和协议下的有效服务参数，不是所有硬件情形下的唯一物理常数。Cube活动、发射间隔、完成延迟、Scalar工作和等待要分别解释。仅通过t(Q)=H+L+(Q-1)II扫描Q，不能唯一拆开H和L。本轮冻结局部服务后再拟合有界静态残差，避免让完整kernel的各引擎参数共同漂移抵消。

BF16在这次NN模型中采用事先固定的两字节几何服务投影，因子为1；没有从测试标签重新拟合dtype系数。因此同静态几何可能得到相同FP16/BF16预测，实际dtype误差分别由真实BF16独立测量评价。

## 独立评价口径

本次1198配置覆盖8个新MNK、两dtype、四种实现及核数3/5/10/18。初始6个MNK在本轮DEV采集前登记，后加2个在完整DEV标签本地读取/拟合前登记。全部模型和1198个预测在任一目标canary前封存。开发集19628配置不作为新独立成绩。

每个正式进程五轮，每轮预热400次、连续计时50次，取批均值，再取五轮中位数；最终三个正式进程取中位数。耗时包括完整kernel中已有转换/归约，不是只有Cube忙碌时间；不包括主机分配、预热、gate或数值检查。

随包`tests/data/independent_validation.jsonl.gz`只保存复算需要的紧凑静态输入、封存预测和三个进程聚合值。预测器不会读取这个文件。它用于回归与精度比较，不能用于训练后冒充独立验证。

新独立同数据基线与当前版：

## 使用边界

当前只接受README列出的NN、FP16/BF16、batch1、已审查模板及暖态协议。合法接口区间不意味着区间内每个未知组合都有5%/20%保证；稳定排序也未清零。模型可用作候选筛选和性能估算基线，不能把一次预测当作真实最优tiling的证明。

不支持FP32、转置/batch扩展、任意新tile/stride/offset/缓存策略、其他设备/SDK或完整融合Attention。使用真实host tiler时应识别实际kernel分支和完整计划，不能只给MNK就假定哪种实现。融合Attention需要另外描述驻留、生产消费与共享调度，不能把独立GEMM启动、转换和workspace费用按tile数机械重复相加。
